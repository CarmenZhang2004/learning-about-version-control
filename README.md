# learning-about-version-control

Author: Carmen Zhang

Solving merge conflicts takes conscious effort, but I can do it!

## My opinions

What I like most about version control: I like that I can always go back to an earlier version of my work if I break something. It makes me feel much safer trying out new ideas, because nothing is ever really lost.

What I find most challenging about version control: Merge conflicts are still a bit stressful for me, especially when I'm not sure which version of the code to keep.
